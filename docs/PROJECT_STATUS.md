## 当前能力边界

- 46 家公司中只有 NVIDIA 具备实时职位列表解析器；
- NVIDIA 当前完整抓取上海岗位详情并保存规范化正文与指纹；
- 其余公司仍依赖核验快照或入口健康探针；
- 首页 6 条推荐来自人工复核快照，不直接使用未审阅实时岗位；
- 变化事件尚无 Inbox API/网页视图，也没有收藏、忽略或待比较状态。

## 风险与阻塞

- Workday 字段或接口结构变化会触发 `structure_changed`，需要更新 Fixture 和解析器；
- 多地点职位依赖 Workday 上海查询结果和主地点推断，未来应持续核验；
- 当前只追踪 NVIDIA，其他 45 家公司尚无批次与变化事件；
- TSMC、SpaceX、Tesla 自动探针受 403 限制，中芯国际存在 TLS 连接异常。

## 下一里程碑

实现岗位变化 Inbox API 与网页视图，支持事件筛选、收藏、忽略和待比较状态。

验收标准：

1. API 可按 `new / updated / closed / reopened` 和处理状态筛选；
2. 用户可收藏、忽略或标记待比较，SQLite 重启后保持；
3. 页面默认展示未处理事件，并链接官方岗位；
4. 不暴露内部公司池、原始 HTML 或未审阅隐私数据；
5. 重复读取 Inbox 不改变事件状态。
