## 当前能力边界

- 46 家公司中只有 NVIDIA 具备实时职位列表解析器；
- NVIDIA 当前只检索并保留上海岗位，列表字段已解析，详情正文尚未摄取；
- 其余公司仍依赖核验快照或入口健康探针；
- 首页 6 条推荐来自人工复核快照，不直接使用未审阅实时岗位；
- 尚未保存抓取批次、内容指纹、关闭状态历史或变化事件。

## 风险与阻塞

- Workday 字段或接口结构变化会触发 `structure_changed`，需要更新 Fixture 和解析器；
- “当前列表存在”只证明岗位 live，不能证明岗位详情内容未变化；
- 没有跨批次持久化时，无法可靠识别新增、更新、关闭和重新开放；
- TSMC、SpaceX、Tesla 自动探针受 403 限制，中芯国际存在 TLS 连接异常。

## 下一里程碑

持久化 NVIDIA 抓取批次和岗位内容指纹，生成 `new / updated / closed / reopened` 变化事件。

验收标准：

1. 相同抓取结果重复运行不产生新事件；
2. 新职位产生 `new`；
3. 字段或详情指纹变化产生 `updated`；
4. 上一批存在、本批缺失产生 `closed`；
5. 已关闭职位再次出现产生 `reopened`；
6. SQLite 重启后仍能继续比较；
7. 不保存 Cookie、账号凭据或不必要的原始页面数据。
