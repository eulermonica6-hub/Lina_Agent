## 当前能力边界

- 46 家公司中只有 NVIDIA 具备实时职位列表解析器；
- NVIDIA 当前完整抓取上海岗位详情并保存规范化正文与指纹；
- 其余公司仍依赖核验快照或入口健康探针；
- 首页 6 条推荐来自人工复核快照，不直接使用未审阅实时岗位；
- 当前自然语言对话仍是类型化预览，不能调用搜索、Inbox 或比较工具。

## 风险与阻塞

- Workday 字段或接口结构变化会触发 `structure_changed`，需要更新 Fixture 和解析器；
- 多地点职位依赖 Workday 上海查询结果和主地点推断，未来应持续核验；
- Inbox 当前只消费 NVIDIA 事件，其他 45 家公司尚无变化数据；
- TSMC、SpaceX、Tesla 自动探针受 403 限制，中芯国际存在 TLS 连接异常。

验收标准：

1. 用户可以自然语言触发岗位搜索、查看动态和比较岗位；

4. `unknown` 不被模型改写成满足或失败；
5. 默认测试不访问公网，工具调用使用可验证 Fixture。
