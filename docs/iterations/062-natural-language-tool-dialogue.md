# 迭代 062：自然语言工具对话第一阶段

> 日期：2026-10-01
> 版本：0.2.44
> 状态：岗位搜索、动态查询、岗位比较和主动追问已完成

## 1. 问题

右侧 Lina 对话此前只是关键词预览，不能真正调用岗位来源、Inbox 或比较逻辑，也无法在偏好不足时指出缺失字段。用户需要通过自然语言驱动已有确定性工具，同时保留官方来源和未知状态。

## 2. 实现

新增 `ConversationalAssistantService`，以确定性意图解析驱动三类工具：

- `job_search`：解析地点、岗位类型、方向和已知公司名，调用岗位发现服务；
- `inbox_query`：查询未处理动态，并支持新增、更新、关闭和重开类型；
- `job_compare`：明确两个公司时按公司搜索；说“前两个”时比较当前已复核推荐；
- 简历意图继续导航到证据化简历匹配入口。

当搜索缺少地点、岗位类型或方向时，返回 `clarification` 和 `missing_fields`，不调用搜索、不自行补默认值。只提供一个比较公司时也会追问第二个目标。

## 3. 响应边界

工具响应包含：

- 工具名称与执行模式；
- 来源 ID 和来源状态；
- 岗位标题、公司、地点、方向、亮点和官方 URL；
- Inbox 公开事件字段；
- 建议导航动作。

不暴露内部公司池、去重键、内容指纹、原始 HTML 或私人数据。未声明条件继续称为 `unknown`，不推断满足或失败。

## 4. 前端

- 侧栏从 `PREVIEW` 更新为 `TOOLS`；
- 快捷提示改为岗位搜索、简历匹配和岗位比较；
- 工具结果在对话中显示可点击岗位与来源状态；
- Inbox 查询显示动态链接；
- 搜索后仍保留现有推荐区和独立 Inbox，不把工具结果伪装成首页人工复核推荐。

## 5. 验收

离线测试覆盖：

- 完整偏好触发岗位搜索；
- 缺地点、类型和方向时主动追问且不调用工具；
- Inbox 新增事件查询；
- 默认前两个比较、明确公司比较和单公司追问；
- 简历导航和未知输入说明；
- API 响应保留官方 URL 与来源状态；
- Playwright 渲染工具链接和来源状态。

真实浏览器验收：“帮我找 NVIDIA 上海 AI 实习”返回 10 条结果摘要，并展示快照与 `nvidia-careers` 的 5 个官方链接，两个来源状态均为 `success`。
