# 迭代 049：首页发现模式与公司准入标准

> 日期：2026-09-28
> 阶段：用户入口聚焦与候选公司评估
> 状态：首页/决策台拆分、上海早期岗位默认值和 Garena/TapTap 评估已完成

## 1. 用户问题

首页同时包含机会发现、结构化画像、单 JD 匹配、文件 Agent 和历史审计，主任务不明确。推荐也没有显式岗位类型，无法稳定优先上海实习/校招或完全远程机会。同时，公司池缺少公开准入标准，难以解释 Garena、TapTap 等公司为什么进入或不进入清单。

## 2. 页面拆分

- `/`：机会首页，只显示 Top 9、公司雷达、搜索、简历初筛和 Lina 对话；
- `/workbench`：结构化画像、单 JD 硬条件和 Run 历史审计；
- 顶部导航允许两页互相切换；
- 共用同一静态模板和脚本，避免复制既有状态逻辑。

主页背景信号保持 `DISCOVER`，决策工具页保持 `MATCH`。

## 3. 默认推荐条件

`JobLead` 新增岗位类型：

- `internship`；
- `campus`；
- `full_time`；
- `unknown`。

首页推荐请求默认偏好地点为上海和明确远程，岗位类型为实习与校招。地点命中和早期岗位命中分别加分，但不覆盖 6 主池 + 3 探索池配额。搜索表单默认显示“上海”和“实习 / 校招”，用户可修改为其他地点、仅实习、仅校招或全部类型。

当前历史快照中的 10 条岗位均为上海实习，因此默认 Top 9 能满足页面布局。真实来源接入后，远程必须由岗位正文明确证明，不能从公司 remote-first 推断每个岗位可远程。

## 4. 公司与岗位判断标准

新增 [公司与岗位准入标准](../COMPANY_SELECTION.md)：

- 公司进入正式池需要官方 Careers、相关方向、地区、关注理由和可监控入口；
- “小而美”使用可观察的“专注型 AI”分类，不自动声称融资或经营状态；
- 岗位按可投性、方向、已有证据、成长价值、机会成本和风险逐层判断；
- hard unmet 保持 veto，公司品牌不能覆盖岗位不适配。

## 5. Garena

官方招聘页可直接读取岗位，并提供 Internship 与 Entry Level 筛选。2026-09-28 可见新加坡 Intern Game Programmer、General Openings (Internships)，以及雅加达 Garena Internship Program 等。

Garena 进入探索池，但属于条件关注：适合接受新加坡/东南亚、游戏工程、数据分析、推荐、增长或产品方向的用户；当前没有上海 AI Agent 岗证据，不进入默认高优先级。

## 6. TapTap / 心动

心动官网确认公司地址位于上海，TapTap 业务与游戏社区、搜索、推荐和数据相关。但 `xd.com/join` 本轮无法提取有效招聘内容，TapTap 页面存在访问挑战，也没有可引用的当前 AI Agent 实习岗位。

因此 TapTap/心动进入待补证名单，不进入正式池或 Top 9。取得稳定官方招聘入口和具体岗位后再晋级。

## 7. 公司目录更新

- 正式目录：10 家主池 + 22 家探索池，共 32 家；
- 每周自动更新 32 个 Careers 入口的健康状态；
- 每月人工复核公司成员资格、方向、地区和入口；
- 用户提名先进入待补证，不直接进入推荐；
- Garena 本轮晋级探索池，TapTap 保持待补证。

## 8. 验证

新增测试覆盖：

- 岗位类型过滤；
- 上海/远程和实习/校招推荐加分；
- 搜索表单默认值及请求字段；
- 首页隐藏结构化画像和历史；
- `/workbench` 保留原有工具；
- 公司目录达到 32 家且 Garena 位于探索池；
- 公司准入文档纳入链接契约。

全量 233 项测试通过，其中 23 项 Playwright；核心语句和分支覆盖率 100%。

## 9. 下一步

优先为 Garena 或其他能直接读取职位列表的来源实现真实岗位解析器。Garena 解析器需保留职位 ID、地点、Job Type 和类别，并仅在标题/描述符合目标方向时进入候选 Feed。
