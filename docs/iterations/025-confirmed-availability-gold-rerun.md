# 迭代 025：候选人投入确认 Gold 复跑

> 日期：2026-09-15
> 阶段：Phase 2B.4 人工确认闭环
> 状态：完成

## 1. 用户事实

用户确认每周可到岗 5 天，可连续实习一年。评测统一换算为 `weekly_days=5`、`duration_months=12`。

确认事实保存在私有 Gold 中，不进入匿名简历，也不生成文档 offset。公开仓库只记录聚合指标。

## 2. 实现

- `CareerMatchingGoldDataset` 新增可选 `candidate_availability`。
- 自动信号评测将确认对象传给 `extract_decision_signals()`。
- 文档证据指标继续只统计简历与 JD 的 `SourceEvidence`，人工确认不计作文档引用。
- 私有 18 项硬条件 Gold 中，9 个到岗/时长状态由 `unknown` 更新为 `met`。

## 3. 结果

| 指标 | 确认前 | 确认后 |
| --- | ---: | ---: |
| 硬条件逐项已知率 | `0.50` | `1.00` |
| 未知硬条件数 | `9` | `0` |
| 逐项状态准确率 | `1.00` | `1.00` |
| 证据 Precision / Recall / 有效率 | `1.00 / 1.00 / 1.00` | `1.00 / 1.00 / 1.00` |
| hard signal MAE | `0.15` | `0.00` |
| Top-1 Accuracy | `1.00` | `1.00` |
| Pairwise Accuracy | `0.70` | `0.70` |

预测排序仍为 `1 > 4 > 2 > 5 > 3`，Gold 排序为 `1 > 2 > 3 > 4 > 5`。

## 4. 结论

人工确认消除了硬条件未知值，并证明确认来源与文档证据可以分离评测。Pairwise Accuracy 没有提高，说明剩余排序误差不再来自到岗或时长缺失，而主要位于方向适配和组合排序。

自动综合排序继续保持显式 opt-in。只有 5 个岗位且 Pairwise 为 `0.70`，不能据此默认启用，也不应通过重新调整硬条件权重掩盖方向误差。

## 5. 下一步

逐岗位分析方向标签与排序逆序对，设计结构化方向语义映射及引用验证；在扩大冻结样本前不调整默认权重。
