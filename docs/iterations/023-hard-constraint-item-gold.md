# 迭代 023：硬条件逐项 Gold 与范围表达

> 日期：2026-09-14
> 阶段：Phase 2B.3 逐项可验证决策信号
> 状态：完成

## 1. 目标

把岗位级 hard score 拆成可定位的逐项状态与证据，并支持真实目录中的届次、城市和实习范围表达。

## 2. 实现

- 支持 `预计毕业：2028 年`、`2027 届及以后` 和基本信息行首城市。
- 支持 `连续 3-6 个月`、`至少 1 年`、`至少持续实习 3 个月`，统一换算最低月数。
- 每个岗位可标注唯一的 `hard_constraint_labels`，包含字段名、`met/unmet/unknown` 和双侧证据文本。
- 自动报告新增逐项已知率、状态准确率、证据 Precision/Recall 和 offset 有效率。
- 硬条件只返回实际用于比较的最小候选证据。

## 3. 私有基线

| 指标 | 结果 |
| --- | ---: |
| 逐项 Gold 数 | `18` |
| 逐项已知率 | `0.50` |
| 状态准确率 | `1.00` |
| 证据 Precision | `1.00` |
| 证据 Recall | `1.00` |
| 证据 offset 有效率 | `1.00` |
| 岗位级 hard signal 覆盖率 | `1.00` |
| 岗位级 hard MAE | `0.15` |
| Pairwise Accuracy | `0.70` |

范围扩展后 `unknown` 从 6 增至 9，不是回退：解析器新识别出此前漏掉的岗位投入要求，而简历没有对应承诺。岗位级覆盖率 `1.0` 也不表示所有候选事实已知，逐项已知率只有 `0.5`。

## 4. 学习与行为变化

1. unknown reduction 不能作为孤立目标；漏掉要求会制造更低但虚假的 unknown 数。
2. 评测最小单位应与错误修复单位一致。范围解析错误必须落到 `duration_months` 状态和证据，而不是只观察岗位总分。
3. 多条真实学历经历不应全部成为比较证据；最小充分证据能提高引用 Precision。
4. 当前剩余缺口主要是候选人未确认每周到岗和持续时长，继续加正则无法解决。

长期约束见 [决策信号行为准则](../DECISION_SIGNAL_RULES.md)。

## 5. 下一步

新增候选人事实确认输入：每周可到岗天数、可连续实习月数及证据来源。确认前保持 `unknown`，确认后重新运行同一逐项 Gold 和排序评测；不先调整权重。
