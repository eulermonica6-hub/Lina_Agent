# 迭代 027：候选人方向偏好确认契约

> 日期：2026-09-21
> 阶段：Phase 2B.6 方向偏好确认
> 状态：领域与私有评测完成；入口接线待完成

## 1. 问题

并列 Gold 修正后，自动排序仍有 `2 > 4` 和 `3 > 5` 两个逆序对。两组岗位内部的离散方向重叠率相同，技能覆盖分因此主导排序。候选人虽然明确以 AI Agent / 大模型应用为主线，但系统无法表达 AI 平台、通用 ML、全栈 AI 测试和风控之间的偏好强度。

## 2. 用户确认

用户确认以下 `0-1` 方向偏好分：

| 方向 | 分数 |
| --- | ---: |
| Agent / 大模型应用 | `1.0` |
| AI 平台 / Infra | `0.8` |
| 通用 Machine Learning | `0.7` |
| 全栈 AI 测试 | `0.0` |
| 风控建模 | `0.0` |

`0.0` 表示不作为目标方向，不表示岗位硬条件不兼容或禁止投递。

## 3. 实现

- 新增 `CandidateDirectionPreferenceConfirmation`，五类方向均为可选 `0-1` 分数。
- 新增 `ConfirmedDirectionPreference`，以 `user_confirmation` 独立记录来源。
- `DirectionEvidenceItem` 分离候选人文档证据与人工偏好确认。
- 将 `CUDA / Full Stack / AI 测试` 从 AI Infra 拆为 `fullstack_ai_testing`，避免平台运维与全栈测试被错误合并。
- 岗位方向分取其命中方向类别的确认分平均值；未确认类别回退到原有文档证据逻辑。
- 私有评测数据集可携带方向确认，但 Agent、API 和 CLI 本轮尚未接线。

## 4. 失败与修复

1. 新契约首轮领域回归在无确认路径触发 `None > 0`。根因是嵌套条件表达式先比较确认值，再判断是否为空。修复为显式 `_direction_status()` 分支，并重跑全部领域测试。
2. 私有评测首轮返回 `direction_alignment=None`。根因是 Gold 模型接受未知字段但评测调用未透传。修复为类型化数据集字段并显式传入抽取器。
3. 岗位 5 同时命中通用 ML 与风控，确认分应为 `(0.7 + 0.0) / 2 = 0.35`，不能沿用近似人工值 `0.3`。

## 5. 验证结果

私有 5 JD 复跑结果：

| 指标 | 确认前 | 确认后 |
| --- | ---: | ---: |
| direction signal MAE | 非零 | `0.0` |
| Top-1 Accuracy | `1.0` | `1.0` |
| Pairwise Accuracy | `0.778` | `1.0` |
| 排序逆序对 | `2` | `0` |

预测排序为 `1 > 2 > 4 > 3 > 5`。岗位 3 与岗位 4 属于 Gold 并列组，因此该顺序完全满足人工偏好。

## 6. 知识与行为准则

- 硬条件事实回答“能不能投”，方向偏好回答“更想投什么”，两者不得混用。
- 偏好强度是用户事实，不应从普通技能出现次数推断。
- `0.0` 是有效偏好值，不等于未知，也不应产生文档证据。
- 岗位命中多个方向时使用明确聚合规则；当前为等权平均，后续若调整必须在冻结 Gold 上消融。
- taxonomy 类别必须可区分真实决策差异；AI Infra 与全栈 AI 测试不能因共享 CUDA/LLM 词汇而合并。

## 7. 风险与边界

- 只有 5 个岗位，Pairwise `1.0` 是当前确认集上的契约验证，不代表生产泛化准确率。
- 偏好分由用户人工确认，尚无 UI、API 或 CLI 输入入口。
- 当前等权平均未区分岗位主方向与辅助方向；扩大 Gold 前不增加复杂权重。
- 自动综合排序继续显式 opt-in，默认行为不变。

## 8. 下一步

将 `CandidateDirectionPreferenceConfirmation` 贯通 Agent、API 和 CLI，并补成功透传、范围校验和未启用自动信号时拒绝的入口契约测试。

## 9. 面试表达

我先用结构化逆序对证明排序误差来自方向偏好缺失，而不是继续调权重。随后把候选人的方向偏好建模为带来源的 `0-1` 确认事实，将 AI Infra 与全栈 AI 测试拆成可决策的类别，并保持人工确认与文档 offset 分离。确认后的私有 Gold 上，方向 MAE 从非零降为 `0`，Pairwise 从 `0.778` 提升到 `1.0`；但由于只有 5 个岗位，我仍保持功能 opt-in，并把下一步限制为入口接线。
