# 迭代 052：右侧停靠 Agent 对话栏

> 日期：2026-09-28
> 版本：0.2.34
> 状态：默认展开、宽度调节、收起与本地偏好已完成

## 1. 问题

首页原有对话入口位于内容区或浮层按钮中，与岗位浏览割裂，也没有形成持续可见的 Agent 工作空间。用户需要类似 VS Code Copilot 或 Chrome Gemini 的右侧栏：浏览岗位时可同时对话，并能按任务调整空间。

## 2. 交互

- 首页首次访问默认展开右侧全高对话栏；
- 桌面端打开时主页面自动让出侧栏宽度，不覆盖岗位内容；
- 拖动侧栏左缘可在 320px 到 640px 之间调节宽度；
- 聚焦分隔线后可用左右方向键微调宽度；
- 点击关闭按钮或按 `Escape` 收起，点击顶部“和 Lina 对话”重新打开；
- 浏览器本地保存开关状态和宽度；
- 移动端使用全宽抽屉，不压缩底层页面；
- `/workbench` 保留“等待输入”等运行状态，不显示对话栏。

## 3. 能力边界

本次只改变对话工作区布局，不扩大 Agent 能力。当前仍是类型化对话预览，可识别岗位查找和简历上传意图；实时联网搜索、多轮记忆与自动投递仍未实现。

## 4. 验收

Playwright 覆盖：

- 首次进入时面板可见且按钮为展开状态；
- 主内容与桌面侧栏不重叠；
- 指针拖拽和方向键均可改变实际宽度；
- 收起后页面恢复，重新打开时输入框聚焦；
- 移动端默认展示全宽抽屉，收起后岗位仍在首屏；
- 决策工具的运行状态与异步防陈旧响应测试保持通过。
