# 迭代 051：首页首屏与对话入口精简

> 日期：2026-09-28
> 阶段：机会首页信息层级
> 状态：岗位进入首屏、对话入口增强和文档入口统一已完成

## 1. 用户问题

首页介绍区、重复 CTA 和展开的筛选器占据过多高度。在常见桌面视口中，首张岗位卡顶部位于 836px，用户进入后必须滚动才能看到推荐。右下角对话入口只有单字母 `L`，含义不明确。

## 2. 首页调整

- 首页标题缩短为“本周值得投的 AI 岗位”；
- 删除首页英文 eyebrow、大型 `DISCOVER` 水印和重复“查看岗位”链接；
- 将首页介绍区从 310px 以上压缩为紧凑标题带；
- 保留一个明确的“上传简历匹配”操作；
- Feed 标题、核验状态和筛选器间距压缩；
- 桌面筛选器保持单行，移动端默认折叠为“筛选岗位 · 上海 · 实习/校招”，展开后采用两列；
- 首张岗位卡在桌面和移动端首屏可见。

`/workbench` 的标题、MATCH 水印和结构化工具布局不受影响。

## 3. 对话入口

对话按钮从 54px 单字母圆钮改为 `L` 标记加“和 Lina 对话”文案：

- 桌面仍固定在右下角，便于随时调用；
- 移动端进入首屏操作区的正常文档流，不覆盖岗位卡；
- 保留 aria-label、展开状态、关闭按钮、Escape 关闭和输入框聚焦。

## 4. 验收

新增移动端专项测试，并扩展桌面首页测试：

- 首张岗位卡在 viewport 中；
- 对话按钮在 viewport 中且包含明确文案；
- 移动端按钮和岗位卡矩形不相交；
- 页面无横向溢出；
- 默认上海、实习/校招和现有对话流程保持不变。

全量 234 项测试通过，其中 24 项 Playwright；核心语句与分支覆盖率 100%。

## 5. 文档审计

根路径统一称“机会首页”，`/workbench` 称“决策工具”。当前只有类型化对话预览，尚无实时搜索工具、多轮记忆、简历优化或职业规划对话。

## 6. 下一步

优先实现站内岗位详情和首个真实来源解析器，让首屏岗位卡能展示完整 JD 与验证时间；随后让 Lina 对话调用搜索和详情工具，而不是只做页面导航。
