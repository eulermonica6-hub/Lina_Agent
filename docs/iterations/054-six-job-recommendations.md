# 迭代 054：六岗位推荐配额

> 日期：2026-09-28
> 版本：0.2.36
> 状态：默认推荐数量与多样性配额已调整

## 1. 问题

首页岗位卡在右侧对话栏展开时采用两列布局。继续展示 9 条会形成不完整的第五行，也增加浏览成本；两列三行的 6 条推荐更适合当前首页。

## 2. 规则

- 首页标题、推荐请求和 `GET /opportunities` 默认返回数量统一为 6；
- 内部公司池细分为国内大厂、国外大厂和探索型，默认推荐各取 2 条；
- 同分项使用当天日期和岗位 ID 生成稳定排序，第二天自动轮换；旧 `week_start` 字段继续作为兼容覆盖；
- 某一池候选不足时，继续按总排序从另一池补足；
- 推荐 API 仍允许调用方显式请求最多 9 条，避免不必要的契约破坏；
- 完整岗位搜索不受首页 6 条限制。

## 3. 验收

- 默认推荐服务返回 6 条，并保持国内大厂、国外大厂、探索型 2+2+2 分布；
- 首页请求体发送 `limit: 6`，渲染 6 张卡片；
- `GET /opportunities` 和推荐 API 默认均返回 6 条 live 岗位；
- 每日轮换、偏好排序、池不足补位和 live-only 边界继续通过测试。
