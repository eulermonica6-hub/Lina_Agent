# 迭代 053：宽松岗位与快捷对话

> 日期：2026-09-28
> 版本：0.2.35
> 状态：岗位降密度、公司 logo 与一键提示词已完成

## 1. 问题

右侧 Agent 栏默认展开后，首页仍同时显示三列岗位和完整筛选控件，信息密度过高。对话栏只有空白输入框，用户需要先组织问题；岗位卡也缺少快速识别公司的视觉信号。

## 2. 交互

- 对话栏展开时岗位使用两列布局，增大卡片内边距和卡片间距；
- 桌面与移动端的岗位筛选均默认折叠，需要时再展开；
- 删除重复的英文 Feed 标签，保留岗位标题、数量、来源状态和刷新入口；
- 对话标题下提供 3 条常用提示词，点击后立即发送；
- 岗位卡展示公司品牌图标，优先使用官方域名资源，加载失败时显示公司首字回退；
- 对话栏收起、调宽和移动端全宽抽屉行为保持不变。

## 3. 能力边界

快捷提示词复用当前类型化对话 API，不代表已经实现开放式规划、实时联网检索或多轮记忆。公司图标是辅助识别信息，失败不会影响岗位来源和投递链接。

## 4. 验收

Playwright 覆盖：

- 首页筛选默认折叠，展开后仍可完成手动搜索；
- 岗位卡包含公司 logo 及可访问名称；
- 3 条提示词均可见，点击后立即发送对应消息；
- 原有侧栏默认打开、拖拽调宽、收起和移动端首屏测试继续通过。
