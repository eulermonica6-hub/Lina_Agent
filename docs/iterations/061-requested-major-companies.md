## 3. 官方入口验证

每家公司均使用官方招聘域名或官方跳转入口。新增 14 家真实 HTTP 健康探针全部返回正文，状态为 `partial/listing_parser_pending`：入口可访问，但尚未实现岗位列表解析器。

## 4. 边界

- 加入大厂池只意味着进入来源监控和召回候选，不代表自动推荐；
- 首页仍按国内大厂、国外大厂和探索型各 2 条分配；
- 只有岗位级状态为 live 且满足地点、类型和偏好时才进入推荐；
- 当前只有 NVIDIA 有真实岗位列表与变化检测，新增 14 家仍需逐步实现解析器。
