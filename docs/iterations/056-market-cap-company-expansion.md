# 迭代 056：科技市值榜扩容

> 日期：2026-09-28
> 版本：0.2.38
> 状态：国内外科技公司 Top 10 已审核并补入大厂池

## 1. 目标

人工审核国内外高市值科技公司，补齐美团、京东等广义平台科技公司，以及全球科技市值头部公司。市值只用于公司发现覆盖，不直接提高岗位匹配分。

## 2. 口径

- 国内采用广义科技口径，覆盖互联网平台、电商、消费科技、内容、搜索和半导体；
- 国外采用 Statista 2026-09-28 全球科技公司市值 Top 10；
- SpaceX 沿用来源榜单的估值比较，但不描述为上市公司；
- 字节跳动、蚂蚁集团和小红书等未上市公司继续保留，但不进入公开市值排名；
- 排名会波动，清单冻结审核日期和来源，不声称永久有效。

完整排名和来源见 [国内外科技公司市值榜审核](../MARKET_CAP_TECH_REVIEW.md)。

## 3. 结果

新增 14 家：

- 国内：拼多多、网易、小米、美团、快手、中芯国际、京东、百度；
- 国外：Alphabet / Google、TSMC、Meta、SpaceX、Broadcom、Tesla。

目录由 32 家扩展为 46 家：13 家国内大厂、11 家国外大厂、22 家探索型公司。首页推荐配额仍为国内、国外、探索型各 2 条；只有 live 岗位才能进入首页。

## 4. 验收

- TOML 可完整解析 46 家公司；
- 国内和国外排名分别且仅覆盖 1–10；
- 公司名称与来源 ID 继续保持唯一；
- 新增公司均使用官方招聘入口；
- 公司池仍不暴露到公共 API 或首页。
