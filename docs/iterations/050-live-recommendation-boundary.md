## 1. 触发原因

全面审计发现首页虽然已有 Top 9，但推荐仍来自全部历史快照，包含已下线或无法确认的岗位；公司池和内部配额直接展示给用户；公司目录 API 也暴露内部召回字段。这与“用户进入首页立即看到真实有效且高推荐岗位”的目标冲突。

## 2. 岗位重新核验

2026-09-28 重新访问具体官方详情页：

- MiniMax 开源 Agent 开发者生态实习生明确显示已下线，标记 `closed`；
- 小红书 AI Agent 研发、基础大模型 Agent 研究本轮无法提取有效详情，保留 `needs_reverification`；
- MiniMax AI Infra、MiniMax 模型评测、字节风控、字节 AI 搜索、Apple ML、Apple AI Tools、NVIDIA CUDA AI Test、NVIDIA CUDA Test、小红书 AI 产品可确认详情和投递入口，标记 `live`；
- 补充 Unstructured 远程 Software Engineer 作为明确远程的探索型岗位。

首页推荐只消费 `live`，不会用 closed 或 unknown 补足数量。完整搜索仍保留状态，供人工复核。

`company_pool` 和 `deduplication_key` 继续用于内部去重与多样性配额，但通过 Pydantic `exclude` 从公共 API 响应移除。

同时删除：

- 首页 Company Radar；
- 岗位卡主池/探索池徽标；
- 公共 `GET /companies`；

公司准入与监控配置留在代码、CLI artifact 和开发文档，不转化为用户标签。
